# Copilot CLI slash commands (from `/help`, v1.0.92)

## Most useful from mobile (suggest in the palette first)
| Command | Purpose |
|---|---|
| `/model` | Pick model |
| `/plan` | Plan before coding |
| `/autopilot` | Toggle autopilot |
| `/permissions`, `/allow-all` | Permission modes |
| `/resume`, `/new`, `/clear`, `/rename`, `/fork` | Session management |
| `/compact`, `/context`, `/usage` | Context management |
| `/diff`, `/review`, `/pr` | Review changes |
| `/tasks` | Subagents and shell tasks |
| `/ask` | Side question, not added to history |
| `/copy`, `/share` | Output |
| `/rewind` | Undo last turn |
| `/help` | Help |

## Everything else

Code: `/ide /security-review /rubber-duck /lsp /terminal-setup`

Other: `/chronicle /collect-debug-logs /computer /env /exit /keep-alive /limits /login /logout /refine /research /restart /search /settings /subagents /user /vim /voice`

## Prefix triggers
`/` commands, `@` file mention, `#` issue/PR, `!` shell.
